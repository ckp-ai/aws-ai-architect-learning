# 00 Program Governance

This folder defines how the AWS AI Architect learning program is governed, measured, and evidenced over a 24-week timeline.

It turns the roadmap into an execution system with:

- Clear learning outcomes
- Baseline and periodic assessments
- Weekly and phase-level planning
- Objective completion gates (Definition of Done)
- Traceable evidence for each claim of progress

## Scope

The governance model applies to all phases:

1. AI/ML foundations
2. SageMaker production ML
3. Bedrock GenAI
4. Enterprise RAG
5. Agentic AI and AgentCore
6. AI security and Responsible AI
7. MLOps/LLMOps
8. Enterprise AI platform
9. Portfolio and solution shaping

## How to use this folder

1. Start with `baseline-assessment.md` and set your initial maturity.
2. Adopt the target outcomes in `learning-objectives.md`.
3. Commit to dates in `study-calendar.md`.
4. Track phase progress weekly in `progress-tracker.md`.
5. Use `skills-matrix.md` for competency growth reviews.
6. Apply `definition-of-done.md` before marking a phase complete.
7. Record proof artifacts in `evidence-register.md`.

## Governance cadence

- **Weekly (30 min):** progress update, blockers, calendar adjustments
- **Bi-weekly (45 min):** skills review and risk review
- **Phase closeout (60 min):** DoD gate review and evidence audit
- **Monthly (60 min):** outcome health and portfolio quality check

## Ownership model

| Role | Accountable for |
|---|---|
| Learner (primary owner) | Delivery of notes, labs, architecture, evaluation, and runbooks |
| Reviewer (peer/mentor) | Architecture quality, security depth, and evidence validity |
| Program steward (optional) | Cadence discipline, milestone tracking, and risk escalation |

## Success signal

The program is successful when all phases are completed with objective evidence, and the portfolio demonstrates enterprise-ready AI architecture decisions, security controls, and operational readiness.
