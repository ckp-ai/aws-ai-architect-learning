# Study Calendar (24 Weeks)

Default commitment: **8-10 hours/week**.

## Weekly cadence template

| Day | Focus | Suggested duration |
|---|---|---:|
| Mon | Concept study notes | 1.5h |
| Wed | Lab execution and troubleshooting | 2.0h |
| Fri | Architecture artifacts (diagrams, ADRs) | 2.0h |
| Sat | Evaluation + security/control updates | 2.0h |
| Sun | Progress update + evidence logging | 1.0h |

|---:|---|---|

| 3-5 | 02 SageMaker production ML | Governed ML pipeline + registry/monitoring artifacts |

| 23-24 | 09 Solution shaping + 10 Portfolio | Final portfolio and interview package |

|---:|---|---|

## Buffer and catch-up policy

- Reserve **one buffer week-equivalent** every 6 weeks (distributed as spare weekly slots).
- If a phase misses target by >1 week:
  - freeze new scope,
  - complete mandatory labs/evaluation first,
  - update target dates in `progress-tracker.md`.

## Review windows

- Weekly review: Sunday
- Phase gate review: last week of each phase
- Portfolio review: week 24
