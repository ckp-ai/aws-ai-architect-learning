# Learning Objectives

These objectives define the expected capability shift from experienced AWS Cloud/Data Architect to Enterprise AWS AI Architect.

## Program-level outcomes

By the end of the 24-week roadmap, the learner should be able to:

1. Select fit-for-purpose AI solution patterns (traditional ML, GenAI, RAG, agentic) from business and risk constraints.
2. Design production-grade SageMaker, Bedrock, RAG, and agentic architectures on AWS.
3. Implement security-by-design, Responsible AI controls, and governance for AI workloads.
4. Establish measurable evaluation and LLMOps/MLOps operating models.
5. Produce decision-quality architecture artifacts suitable for enterprise review boards.

## Phase-level objectives

| Phase | Objective | Observable outcome |
|---|---|---|
| 01 AI/ML foundations | Build architectural fluency in ML lifecycle and model evaluation | Can justify ML pattern choice and quality metrics for a use case |
| 02 SageMaker production ML | Design governed training and inference pipelines | Delivers reproducible ML pipeline with monitoring and runbooks |
| 03 Bedrock GenAI | Architect secure enterprise GenAI applications | Ships guarded Bedrock app with structured output and cost controls |
| 04 Enterprise RAG | Build secure retrieval architectures | Produces multi-tenant RAG design with evals and threat model |
| 05 Agentic AI | Design controlled tool-using agents | Implements approval-aware agent workflow and trace-based evaluation |
| 06 AI security | Operationalize AI threat and Responsible AI controls | Completes governance and controls pack for AI workloads |
| 07 MLOps/LLMOps | Build CI/CD and continuous evaluation discipline | Defines quality gates and regression processes across AI assets |
| 08 AI platform | Extend landing zone for enterprise AI platform services | Produces platform reference architecture and operating model |
| 09 Portfolio | Synthesize delivery artifacts into decision-ready portfolio | Presents defensible end-to-end architecture narratives |

## Quantified targets

- **Completion:** 100% phases completed with DoD evidence
- **Lab execution rate:** >= 90% mandatory labs completed successfully
- **Architecture coverage:** 100% required architecture views per phase
- **Evaluation coverage:** 100% phases include evaluation criteria and results
- **Security coverage:** 100% phases include applicable controls and risk notes
- **Portfolio readiness:** at least 3 flagship projects with complete artifact sets

## Non-objectives

The program intentionally does **not** focus on:

- Relearning core cloud/networking/IAM fundamentals already mastered
- Certificate-first prep without practical architecture output
- Notebook-only experimentation without production architecture context

## Objective review checkpoints

- **Week 2:** validate foundational objective trajectory
- **Week 9:** validate GenAI architecture depth
- **Week 17:** validate agentic architecture and control maturity
- **Week 22:** validate platform/LLMOps operating model completeness
- **Week 24:** validate final competency statement and portfolio defense
